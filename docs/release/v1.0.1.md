# v1.0.1 - Documentation build fix

`global-lib` 1.0.1 fixes the docs.rs build. The documentation builds on docs.rs again. The crate root asked nightly rustdoc for the `doc_auto_cfg` feature, which nightly has since folded into `doc_cfg` and removed, so the docs.rs build of 1.0.0 failed (`E0557`). It now asks for `doc_cfg`. No code change.

```toml
[dependencies]
global-lib = "1.0"
```
